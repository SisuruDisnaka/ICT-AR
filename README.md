# 🌐 ICT Sisuru AR

### Explore the Innovative World

An interactive, browser-based Augmented Reality (AR) experience that brings custom animated 3D characters into the real world using webcam-based marker tracking.

## ✨ Features

- Browser-based Augmented Reality.
- Marker-based object tracking.
- Custom animated 3D characters.
- Real-time webcam integration.
- Interactive 3D object explorer.
- Laptop and mobile browser support.

## 🛠️ Tech Stack

- React + TypeScript
- Vite
- Three.js
- AR.js
- HTML5 + CSS3

## 📷 How to Use

1. Open the application.
2. Select a 3D character.
3. Click **Explore in AR**.
4. Allow camera access.
5. Show the supported AR marker to your camera.
6. Enjoy the augmented reality experience!

## 🔒 Requirements

- Modern web browser.
- Webcam or external camera.
- Camera permissions enabled.
- HTTPS for public deployments (localhost is supported for development).
